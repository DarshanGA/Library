For code syntax highlighting, this app uses library. To import additional language syntaxes, refer to the official documentation link below.

Also, when you npm install prismjs, you only get core + a few basics (markup, CSS, JavaScript, etc.). Languages like TypeScript, Java, Python, etc. are separate components under prismjs/components/.

If you want to know the exact name of the module to import, you can navigate under [ node_modules > prismjs > components ] to look for desired language syntax to import.

PrismJS language files aren’t all standalone. Some depend on base grammars (like markup, clike, or bash). So if you only import prism-git without prism-bash, Prism can’t properly register it — resulting in no highlighting.
