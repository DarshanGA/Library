In Angular, [ngClass] is exactly what you’d use to conditionally control which classes an element has.

a. With an object.

We can specify the class names as 'Keys' and boolean data as their values to decide which class to apply. The class names/keys with 'true' values will be applied to the element.

b. With an array of css classes inside of an object.

Ultimately, we can use this directive to add or remove css classes to HTML elements based on a condition or flag. To know more about the usage of this directive, we can visit Angular's official .

Problem:

When the angular re-rendered the page via the app routing, the prismJs syntax highlighting was not getting applied.

Fix:

Using angular's attribute directive approach to re-apply the highlight styles on the page rendering.

We need to create a directive decorated class with an attribute selector like ‘appPrismHighliter’ which would later be added to the element for which the styles need to be updated. Then the class would implement angular’s ‘AfterViewInit’ interface to provide the method to apply the styles after the HTML view has been rendered. Then we need to import the ‘prismjs’ class from installed node package (we need to install types for prismjs explicitly if it throws type related error, we can use this node command: ) and use prism.highlightElement() method to highlight the elements that are tagged with the selector.

Once the directive is setup and ready, we need to import this in the component where we plan to use this and then have this ‘appPrismHighliter’ selector mentioned as a property on the desired html tag in that component’s template.
